<Update label="September 2026">
  September's update puts creative approvals front and centre, with a much-improved
  Public Preview that tracks feedback from first share to final sign-off. It also
  brings new ways to filter and organise campaign work, a Reporting API for pulling
  data into your own tools, and a long list of fixes that make everyday tasks more
  dependable.

  ## Smarter creative approvals

  **Public Preview, now with approval history.** You can now generate a Public
  Preview directly from a line item's **Creatives** tab. A new Public Preview
  History section shows how far each preview has progressed through feedback and
  flags any creatives that have changed since the link was shared, so you always
  know whether approvers are looking at the latest version.

  The preview page has been refreshed for approvers too. It now displays your
  client name and logo, remembers the approver's email address, shows progress
  counts, offers a PDF download, and confirms when feedback has been submitted.
  Line item assignees and the person who created the link receive in-app and
  email notifications every time a creative is approved or rejected.

  **Original and Ready labels on brief assets.** Assets on Campaign and Line Item
  Brief tabs can now be labelled "Original" or "Ready" when you add or edit them,
  making it easy to tell source files from production-ready versions at a glance.
  Thumbnails show the label, along with the URL for single uploads or the upload
  date for bundles. Existing assets start unlabelled.

  **Clearer file thumbnails.** Uploads that aren't images or videos now show an
  icon for their file type, covering links, PDFs, spreadsheets, presentations,
  documents, zip files, code and audio.

  ## Smarter campaign management

  **Find what's missing with the "Is not" filter.** The Line Item filter panel
  has a new "Is not" toggle that shows line items that don't match your chosen
  filters. For example, you can quickly find every line item without an
  EvidenceReady or EvidenceSent tag.

  **A clearer Line Item Overview.** The top of the Line Item Overview tab now
  uses a two-column layout, placing key metrics such as Buy Rate side by side
  and cutting down on scrolling.

  **More flexible product assignees.** Any client user role can now be assigned
  at product level, and products can have multiple assignees. Product assignees
  automatically become collaborators on every line item created with that
  product, so the right people are involved from the start.

  **More reliable bulk edits.** Bulk edits across larger selections now show a
  progress indicator and complete reliably, rather than timing out part-way
  through.

  ## Reporting and documents

  **New Reporting API.** A new Reporting API lets you pull your Uplift Hub
  reporting data straight into your own systems. Requests authenticate with
  your Uplift Hub API key, and you can choose which columns to return and page
  through larger result sets. If you'd like to get set up, speak to your
  Platform 195 representative.

  **Automated evidence in generated documents.** Automated evidence screenshots
  can now be included in generated documents alongside manually uploaded
  evidence.

  ## Working across markets

  **Multi-currency campaigns, now running live.** Multi-currency support, which
  we introduced in January, is now switched on and running live campaigns.
  Teams can book and manage campaigns in local currencies within a single
  client account, while reporting stays consistent in the client's default
  currency, with exchange rates applied by date. Budgets on multi-currency
  campaigns can be adjusted at both campaign and line item level. If you operate
  in more than one currency and would like this feature enabled, please contact
  your Platform 195 representative.

  ## Better user experience

  - Table and Timeline views now show a horizontal scroll bar when content
    overflows.
  - Collapsed line item sections on the Evidence tab show how many evidence
    images each one holds.
  - The Filters panel has been restyled, with clearer labels and consistent
    Apply Filters buttons.
  - The Campaign dropdown in "Add new line item" is now searchable.
  - Campaign Documents now uses the same drag-and-drop upload as the rest of
    the Hub.
  - Fields and templates in the New Product popup now expand in place, with no
    more popups on top of popups.
  - Truncated names now show in full on hover in the Creatives tab and
    breadcrumb dropdown.
  - Typing in the tag field now narrows the list to matching existing tags.

  ## Key fixes

  - Tags can now be added to live campaigns and line items without being
    blocked by validation errors.
  - Missing required fields are now highlighted across creative, product,
    campaign, line item, account, resource and evidence forms.
  - Where a product requires a Click URL, creatives can no longer be saved
    without one.
  - Keyword targeting uploads now warn you when the file leaves out keywords
    still in use, rather than failing silently.
  - Platforms, channels and account types that are in use can no longer be
    deleted; you'll see which products or accounts use them instead.
  - Collapsed creative components now show their values and can be edited
    straight away.
  - Line item Kanban cards within a campaign now show the line item name.
  - Line Item Notes now keep line breaks, matching Campaign Notes.
  - Automated screenshots are more reliable, including dark backgrounds,
    carousels and accurate "last captured" dates.
  - The targeting component no longer cuts off content on smaller screens.
  - The Accounts table now keeps consistent column widths and wraps long names.
