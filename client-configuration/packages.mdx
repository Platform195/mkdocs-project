A **package** is a predefined bundle of products sold together. When someone
creates a **Package** campaign, Uplift Hub generates the line items for every
product in the package automatically. Set packages up here so your team can
sell them consistently. See [Package vs Custom](/setup/create-campaign#package-vs-custom)
for how packages work on a campaign.

## Create a package

<Steps>
  <Step title="Open Packages">
    Select <Ui>Configuration</Ui> in the sidebar, then click the
    <Ui>Packages</Ui> tile.
  </Step>
  <Step title="Add a package">
    Click <Ui>Add Package</Ui> in the top right.
  </Step>
  <Step title="Enter the details">
    Enter a **Package Name**, choose a **Package Type** (see below) and enter
    the **Budget**.
  </Step>
  <Step title="Set the self-serve tier (optional)">
    If the package is sold as a self-serve option, choose a **Self Serve
    Package** — `Core`, `Core+` or `Premium`.
  </Step>
  <Step title="Save">
    Click <Ui>Save</Ui>, then open the package from the list to add its products.
  </Step>
</Steps>

  <img src="https://cdn-uplifthubs.s3.eu-west-2.amazonaws.com/Documentation/client-config-packages-new.png" alt="New Package dialog with name, package type, budget and self serve fields" />

### Fixed or blended

| Package type | How it works |
| --- | --- |
| **Fixed** | Set a quantity and rate for each product. The package's total budget and quantity are added up from all its products. |
| **Blended** | Set one total budget and quantity, then split them across products by percentage share. Every product is charged at the same blended rate. |

## Add products to a package

<Steps>
  <Step title="Open the package">
    Click the package name in the **Packages** list. The **Details** tab opens.
  </Step>
  <Step title="Select a product">
    Under **Products**, use the <Ui>Select a Product</Ui> dropdown to add each
    product in the bundle.
  </Step>
  <Step title="Set quantities and rates">
    Enter the **Quantity** and **Rate** for each product. The **Budget** column
    and the package's **Total Commitment** update as you go.
  </Step>
  <Step title="Save">
    Click <Ui>Save Changes</Ui> in the top right.
  </Step>
</Steps>

To remove a product, click the **⋮** menu at the end of its row and select
<Ui>Delete</Ui>.

## See campaigns using a package

The **Campaigns** section at the bottom of the **Details** tab lists every
campaign sold with this package, with its status, account, dates and budget.

- Click <Ui>Add Campaign</Ui> to add a campaign to the package.
- Click the arrow next to <Ui>Add Campaign</Ui> and select <Ui>Export CSV</Ui>
  to download the list.

## Package tabs

| Tab | What it's for |
| --- | --- |
| **Details** | Package name, type, budget, products and linked campaigns. |
| **Self Serve** | The self-serve tier (`Core`, `Core+` or `Premium`) the package belongs to. |
| **History** | Who changed the package and when. |
| **Settings** | Delete the package. |

<Warning>
  Deleting a package from the **Settings** tab can't be undone.
</Warning>
