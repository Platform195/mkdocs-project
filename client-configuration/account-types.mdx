import { Ui } from "/snippets/ui.mdx";

**Account types** categorise the advertisers you set up as
[accounts](/setup/add-account) — for example `Hotels` or `Tourist Board`.
Use them to keep your account list consistent and make it easier to filter and
report on similar advertisers.

## Add an account type

<Steps>
  <Step title="Open Account Types">
    Select <Ui>Configuration</Ui> in the sidebar, then click the
    <Ui>Account Types</Ui> tile.
  </Step>
  <Step title="Add a new type">
    Click <Ui>Add Account Type</Ui> in the top right.
  </Step>
  <Step title="Name it">
    Enter an **Account Type Name**, then click <Ui>Create Account Type</Ui>.
  </Step>
</Steps>

<Frame caption="The New Account Type dialog.">
  <img src="https://cdn-uplifthubs.s3.eu-west-2.amazonaws.com/Documentation/client-config-account-types-new.png" alt="New Account Type dialog with a name field" />
</Frame>

---

## Rename an account type

Click the account type's name in the list. Update the **Account Type Name**
and click <Ui>Save Account Type</Ui>.

---

## Delete an account type

Click the **⋮** menu at the end of the row and select <Ui>Delete</Ui>.

<Warning>
  Check that no accounts still use an account type before you delete it.
</Warning>

<Tip>
  Keep the list short and use plural, generic names (`Hotels`, `Airlines`,
  `Tourist Boards`). Use [tags](/more/tagging) for anything more specific.
</Tip>
